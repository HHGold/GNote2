# GNote2 Web — 網頁版說明

與手機 App 使用同一個雲端專案，資料即時同步。

## 📁 檔案
```
gd/
├── index.html   介面
├── style.css    樣式
└── app.js       邏輯（Firebase Auth + Firestore）
```

## 🚀 本機測試

必須使用 HTTP 伺服器（使用 ES 模組，不能直接用 `file://` 開啟）：
```powershell
python -m http.server 8080 --directory ".\gd"
```
開啟 **http://localhost:8080**。

## ✨ 功能

| 功能 | 說明 |
|------|------|
| 🔐 Google 登入 | 彈出視窗登入；登入狀態只在分頁存在期間有效（關閉即登出） |
| 📋 全部筆記 | 顯示個人筆記 |
| 📁 資料夾 | 新增 / 重新命名 / 刪除 |
| 🤝 與我共享 | 顯示他人共享給你的筆記，可編輯標題與內容 |
| ✏️ 新增筆記 | 右上角 ✏️ 按鈕 |
| 💾 自動儲存 | 停止輸入 1.2 秒後同步 |
| 🔍 搜尋 | 側邊欄搜尋框 |
| 🗑️ 刪除筆記 | 編輯器右上角 |

> ⚠️ **注意**：網頁版**不會**遮蔽手機端「已上鎖」的筆記，登入後即可閱讀。手機端的鎖只保護手機本機。

## 🔄 資料同步
- 即時雙向同步（Firestore `onSnapshot`）。
- 手機修改 → 網頁立即更新；網頁修改 → 手機立即同步。
- 同一筆記在兩端同時編輯時，網頁會跳出衝突對話框讓你選擇保留版本。

## 🌐 資料結構
```
users/{uid}                    個人資料
users/{uid}/folders/{id}       資料夾
users/{uid}/notes/{id}         個人筆記
users/{uid}/sharedInbox/{id}   別人共享給我的筆記
emailLookup/{email}            email 對照表
```
存取規則：專案根目錄的 [`firestore.rules`](../firestore.rules)。

## ⚙️ 部署
把 `gd/` 資料夾內容上傳到任何靜態網站空間即可。更新後請在瀏覽器按 **Ctrl+F5** 清除快取。

## 📱 響應式設計
- 桌面版：三欄佈局（側邊欄 + 筆記列表 + 編輯器）。
- 行動版：單頁切換（點選筆記展開編輯器，返回按鈕回列表）。
